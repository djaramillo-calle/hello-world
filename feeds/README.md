# feeds/

Personal podcast feeds for narrow listening, served raw from this repository
so AntennaPod can subscribe and gpodder can count the minutes.

- `arendt-origins.xml` — the 14 chapter-by-chapter episodes of *Reading Hannah
  Arendt with Roger Berkowitz* on *The Origins of Totalitarianism* (Sep 2023 –
  Feb 2024), which the show's own RSS no longer lists (it serves the latest
  100 episodes only), plus BBC *In Our Time: Hannah Arendt* as episode 0.
  Audio streams from the publishers' servers; the feed only links to it.
  Rebuilt by the snippet in the commit that created it; regenerate if a URL dies.
